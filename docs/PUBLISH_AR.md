## GitHub

اسم المستودع المقترح: `internal-portscan-to-webshell-investigation`

الوصف المقترح:

`Wireshark case study: internal SYN scan, PHP web-shell upload, confirmed command execution, and interactive shell evidence.`

المواضيع المقترحة:

`wireshark`, `network-forensics`, `soc`, `incident-response`, `pcap-analysis`, `cybersecurity-portfolio`

1. فك ضغط الحزمة وافتح المجلد internal-portscan-to-webshell.
2. أنشئ مستودعًا في حسابك بالاسم المقترح. تحقق من شروط نشر حلول مصدر التمرين قبل جعله عامًا؛ لم يُقدّم رابط المصدر أو شروطه ضمن الأدلة.
3. ارفع محتويات المجلد مع الحفاظ على بنية evidence وdocs وsocial. اجعل README.md في جذر المستودع مباشرة.
4. استخدم رسالة commit: `Add documented Wireshark investigation and sanitized evidence`.
5. افتح README ثم Full investigation وتحقق من ظهور الصور. ثبّت المستودع ضمن المشاريع المميزة في حسابك.
